# 🦙 Ollama Workflow
_______________________________________________________________________________

### How to view a list of installed models
```bash
ollama list
```
_______________________________________________________________________________

### Where to search for models
```
https://ollama.com/search
```
_______________________________________________________________________________

### How to download a model

E.g. I want to download the model `llama3.2:3b`

```bash
ollama pull llama3.2:3b
```

Note: 
- `llama` is the name of the AI model
-  `3.2` is the version
- `:3b` means 3 billion parameters

The more parameters, the more intelligent the model is but the larger 
the download size will be.

You view all valid options and the size of each download here
```
https://ollama.com/library/llama3.2/tags
```
